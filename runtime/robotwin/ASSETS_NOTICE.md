# RoboTwin A2B Runtime Assets

This mirror contains the exact RoboTwin 2.0 scene and robot assets referenced
by `assets.json`, including the background textures used during data collection.
It contains no trajectories, checkpoints, credentials, or private training runs.

Source: https://github.com/RoboTwin-Platform/RoboTwin

The accompanying runtime source archive retains RoboTwin's MIT copyright and
license in `LICENSE`. The original object and embodiment asset README files
declare MIT License. Asset-specific license and attribution files, where present
in the registered inventory, are preserved. SAGE does not assert new ownership
of these third-party assets; upstream asset terms continue to apply.

The two cuRobo configuration files are the path-relocated copies bundled in
`runtime/robotwin/configs/`. Their original and distributed hashes are recorded
in `assets.json`; all other asset bytes are unchanged from the locked inventory.
