# Third-Party Components

This repository vendors the `stable_worldmodel` runtime from
[`galilai-group/stable-worldmodel`](https://github.com/galilai-group/stable-worldmodel),
which is distributed under the MIT license. The original project metadata lists
Lucas Maes, Quentin Le Lidec, and Randall Balestriero as authors.
The upstream copyright and license text are retained in
[`runtime/licenses/stable-worldmodel-MIT.txt`](runtime/licenses/stable-worldmodel-MIT.txt).

SAGE model and planner code is built on that runtime. Please cite both the SAGE
paper and the corresponding LeWM/StableWM work when using this release.
# Native runtimes

The separately staged RoboTwin 2.0 A2B source snapshot retains its MIT license
and source-file checksums. RoboTwin object, robot, and texture assets retain
their upstream terms and are distributed separately; their redistribution
review is a release prerequisite. LIBERO is installed from the upstream commit
listed in `runtime/native_contracts.json`, with its upstream asset licenses.
